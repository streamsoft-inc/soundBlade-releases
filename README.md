# soundBlade — Releases

Builds of **soundBlade 3.0** for testers. This repository distributes the
application; it is not where soundBlade is developed and contains no source
code.

## Downloading

Open [Releases](../../releases) and download the `soundBlade 3.0 <version>.zip`
asset from the newest entry. That zip contains the signed, notarized installer.

soundBlade also checks here for updates itself, so an existing install will
offer a new version when one is published.

Releases are marked **pre-release** while soundBlade 3.0 is in beta. That is
expected — it does not mean the build is unfinished or untested.

## About the "Source code" downloads

Every release also lists **Source code (zip)** and **Source code (tar.gz)**.
Those are generated automatically by GitHub for the release's tag and cannot be
turned off. They contain only this README.

**They are not soundBlade's source, and they are not the application.** If you
are looking for the build, use the `soundBlade 3.0 <version>.zip` asset above.
